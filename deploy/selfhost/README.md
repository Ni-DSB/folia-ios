# Folia 自托管 · 手机 PWA 方案

把二创后的 Folia（含插件音源）跑成手机能用的网页应用。**完全免费、无需服务器、无需域名、跨网络可用、iPhone 可加主屏幕。**

## 它是什么

桌面版的插件音源引擎跑在 Electron 主进程里，网页版没有主进程；而各音乐平台的接口不允许浏览器跨域读取（实测 bilibili 403、网易云/猫耳无 CORS 头）。所以本方案把插件引擎搬到 **Node 服务端**，由它代发请求、代理音频——手机浏览器只管放音。

```
iPhone / 任意网络
   │ HTTPS（Cloudflare 边缘）
   ▼
Cloudflare Quick Tunnel   ← 免费、免注册、免域名
   │ 本机主动外连，无需公网 IP
   ▼
你的电脑 deploy/selfhost/server.mjs (127.0.0.1:8081)
   ├─ /               Web 前端（歌词动画、AI 主题、搜索…）
   ├─ /netease/       网易云 API（进程内挂载）
   ├─ /kugou/         酷狗 API（反代 127.0.0.1:3901）
   ├─ /qq/            QQ 音乐 API（反代 127.0.0.1:3902）
   ├─ /custom-source  插件音源引擎（复用桌面版那 7 个文件）
   └─ /media-proxy    音频代理：带 Referer/UA、改写 m3u8
```

三个官方平台的登录与播放都走本机后端，和桌面版各自内嵌的那套是同一批 npm 包。

## 启动

```powershell
powershell -ExecutionPolicy Bypass -File .\start-folia-selfhost.ps1
```

脚本自动：构建前端（若过期）→ 起服务 → 建隧道 → 公网验证 → 打印地址并写入 `bin/folia-url.txt`。

手机用 **Safari** 打开地址 → 分享 → **添加到主屏幕**。

## 用法

| 做什么 | 怎么做 |
|---|---|
| 搜歌 | 点搜索 → 输入 → 顶部标签切源（bilibili/汽水/咪咕/猫耳…）→ 点歌播放 |
| 加/删音源 | 设置 → 连接与集成 → 自定义音源 → 粘贴插件 URL 或脚本文本 |
| 官方平台登录 | 点头像 → 选 QQ音乐/网易云/酷狗 → 扫码（插件源无需登录，不在这里） |

已内置 8 个实测可用的源：bilibili、汽水、咪咕、网易云、千千、一听、5sing、猫耳FM。

## 更新后手机上不生效？

PWA 有 Service Worker 缓存。换了新构建后如果界面没变：

1. 把主屏幕图标**删掉重新添加**（最可靠）；或
2. Safari 里打开地址 → 下拉刷新；或
3. 设置 → Safari → 高级 → 网站数据 → 删除该站点的数据后再打开。

注：换隧道地址等效于换站点，缓存会自动隔离。

## 必须知道的代价

- ❌ **电脑必须开机且不睡眠**（电源计划设「永不睡眠」）。关机即断。
- ⚠️ **地址每次重启脚本都会变**（Quick Tunnel 随机分配）。换地址后：手机要**重新添加到主屏幕**、要**重新登录**（登录态按域名隔离）。
- ⚠️ 音频走隧道转发，听歌速度受隧道带宽影响（比桌面版直连慢）。

## 安全

- `/media-proxy` 只接受本服务签发的一次性 token，不接受调用方给的任意 URL，不会被当开放代理。
- 插件是第三方代码，在服务端拥有该进程的权限——只装你信任的源。
- **不要公开分享地址**：你的电脑会成为向公众分发内容的节点，风险自负。仅供自用。

## 文件

| 文件 | 用途 |
|---|---|
| `server.mjs` | 自托管服务（前端 + 网易云 + 插件引擎 + 音频代理） |
| `start-folia-selfhost.ps1` | 一键启动 |
| `data/custom-sources/` | 已装插件（持久化，重启不丢） |
| `../bin/`（脚本引用） | cloudflared、当前地址、日志 |

构建命令：`npm run build:selfhost`（产出带 `/netease`、`/custom-source` 的 dist）。
